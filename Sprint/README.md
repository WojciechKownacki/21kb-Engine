# 21kb Engine Sprint Backlog

This is the canonical index for the engine sprint backlog. Every sprint has its own file under [`sprints/`](sprints/), containing its objective, subsystem sections, and complete task checklist.

The sprints are outcome-based and have no calendar deadlines. A task is checked only after its required implementation and verification are complete. For agent execution rules, validated work items, ownership, dependencies, and evidence, see the [Agent Execution Policy](roadmap/AgentExecutionPolicy.md).

The original source inventory is retained unchanged in [the roadmap archive](roadmap/archive/CapabilityInventory-2026-07-25.md) for traceability. The sprint files below are the active human-readable task lists.
